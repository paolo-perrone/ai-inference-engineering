quoted verbatim with its line number (a placeholder that wraps over several lines is joined
onto one), and the subcommand and result field that fill it. Fields are paths inside
`results/<id>.json` under `values`; `<p>` is `bf16`, `fp8` or `awq`. Each timed field is a
cell with `median`, `spread_pct` and the five `runs`.

`test_run.py` re-reads the draft and fails if a placeholder has no row here, if a row's line
number is wrong, or if a row names a subcommand `run.py` does not have.
